# UI — `useUI`

`useUI` manages all application UI state: responsive breakpoints, the navigation sidebar, and the side panel.

---

## Usage

```js
import { useUI } from "@/composables/useUI.js";

const { isDesktop, isPanelVisible, setActivePanel, openPanel } = useUI();
```

State is shared across all components via module-level refs — no Vue inject context required.

---

## Responsive breakpoints

`useUI` tracks `window.innerWidth` via a resize listener and exposes three computed flags.

| Computed | Type | Condition |
|----------|------|-----------|
| `isDesktop` | `boolean` | `width >= 992px` |
| `isTablet` | `boolean` | `768px ≤ width < 992px` |
| `isMobile` | `boolean` | `width < 768px` |

On resize, `isNavVisible` is auto-managed: forced `true` on desktop, hidden on small screens if not explicitly expanded.

---

## Panel

The side panel shows one active tab at a time. Built-in tabs: `view`, `settings`, `about`, `privacy`. Features can add more via `addButton({ panel: { ... } })` in their feature context, or register a panel-only tab (no toolbar button) via `addPanel({ id, icon, title, component })` — registered into `navigatorPanels` and rendered in `.panel-nav` via `panelTabs` ([`src/components/ui/panels.vue:39`](../src/components/ui/panels.vue#L39)).

### `setActivePanel(id)` — switch active tab

```js
setActivePanel("settings");
```

Emits a `panel:change` event.

### `openPanel()` — open the panel

```js
setActivePanel("recordings");
openPanel();
```

Closes the mobile nav if open.

### `togglePanel()` / `closePanel()`

- `togglePanel()` — opens if closed, closes if open (on mobile: always opens)
- `closePanel()` — closes the panel without changing the active tab

## Full API

### State (refs)

| Name | Type | Description |
|------|------|-------------|
| `width` | `number` | Current `window.innerWidth` |
| `isNavVisible` | `boolean` | Navigation sidebar visible |
| `isNavExpanded` | `boolean` | Nav expanded |
| `isPanelVisible` | `boolean` | Side panel open |
| `isPanelExpanded` | `boolean` | Panel expanded (mobile) |
| `activePanel` | `string` | Active panel tab ID (default: `'view'`) |
| `isFirstLoad` | `boolean` | True when no persisted view exists |
| `showAboutModal` | `boolean` | About modal visible |

### Computed

| Name | Type | Description |
|------|------|-------------|
| `isDesktop` | `boolean` | `width >= 992px` |
| `isTablet` | `boolean` | `768px ≤ width < 992px` |
| `isMobile` | `boolean` | `width < 768px` |

### Actions

| Name | Signature | Description |
|------|-----------|-------------|
| `setActivePanel` | `(id)` | Switch tab, emit `panel:change` |
| `openPanel` | `()` | Open panel |
| `togglePanel` | `()` | Toggle open/closed |
| `closePanel` | `()` | Close panel |
| `togglePanelExpanded` | `()` | Toggle expanded state |
| `toggleNav` | `()` | Toggle nav sidebar |
| `closeNav` | `()` | Close nav |
| `closeAboutModal` | `()` | Hide modal, mark first load complete |
| `openAboutModal` | `()` | Show modal |

## CSS classes

The main structural classes used by the app:

| Class | Element |
|-------|---------|
| `.onrte-root` | Root div wrapping everything |
| `.onrte-top` | Top navigation bar container |
| `.onrte-map` | MapLibre map container |
| `.onrte-panel` | Bootstrap offcanvas side panel |
| `.onrte-map.panel-open` | Map shifts right when panel is open on desktop |
| `--onrte-panel-width` | CSS custom property: panel width (set in theme.scss) |
